“Most reviewed books” — restyled

A drop-in replacement for the featured-books band in frontend/templates/partials/home.html. Same content, same brand hue, same Tailwind utilities the project already ships. Covers below are drawn in CSS because this file is standalone — in the template they stay book.cover_url.

  • →The ground now separates from the cards. blue-700→blue-600 against gray-900/80 cards was only a few steps of value apart; the band goes deeper so a card reads as an object sitting on it.
  • →Covers keep their 2:3 ratio. h-56 object-cover crops every jacket differently; four books now line up on a common baseline.
  • →The cover leads, the rating follows. The star row used to sit above the image, so the eye met metadata before the book.
  • →Rank is on the cover. The section is a ranking by review count, so the numeral carries real information — it isn't decoration.
  • →A missing cover no longer breaks the row. {% if book.cover_url %} has no else today, so a book without a jacket collapses its card. The fourth card shows the fallback.
  • →The logo is used at its real size. A 110×79 PNG was sitting inside a hero-scale pulsing glow ring with no job; it becomes the eyebrow's brand chip, and the glow becomes one soft light behind the grid.
  • →There's a way out of the section. “Browse all books” gives the band a next step.
