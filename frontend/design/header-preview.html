What changed

Mobile menu
The current header has no breakpoint below md: nav and both buttons stay on one 56px row and overflow. Added a hamburger and a collapsible panel with nested sub-lists.
Sub-menus
MenuItem.children is prefetched in render_menu but never rendered. menu.html should recurse into a dropdown panel.
URLs
The template prints {{ item.url }}, so items that use named_url render an empty href. Use {{ item.get_url }}.
Active state
Current item marked with aria-current="page" and a blue underline, instead of no state at all.
Layout
Dropped flex-1 on both sides and the &nbsp;&nbsp;&nbsp; spacer; brand / nav / actions now sit on gap-based flex with ml-auto.
